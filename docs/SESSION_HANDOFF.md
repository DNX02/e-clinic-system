## Как работаем
- Владелец общается на русском. Он не программист: объяснять просто, команды давать готовыми блоками.
- Изменения: правка → `npm run test:product`, `npm run test:ui`, `npm run test:e2e` → push в `main`
  (владелец разрешил) → автодеплой → проверить `/api/health` (`commit`) и `npm run check:prod`.
- При изменении `public/app.js`/стилей: поднять `CACHE_NAME` в `public/sw.js` (сейчас `medical-mobile-v98`)
  и `?v=` у `app.js`/`styles.css` во всех 7 HTML.
- Не трогать клинические пороги и формат `POST /api/nurse-surveys`.
- Данные пациентов не коммитить в репозиторий.
