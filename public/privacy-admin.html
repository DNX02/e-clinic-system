Политика конфиденциальности E-Clinic Admin

Приложение E-Clinic Admin предназначено для авторизованного доступа администраторов к медицинской web-системе.

Какие данные обрабатываются

Система может содержать данные врачей, медсестер, пациентов, анкет, результатов тестов и медицинских назначений.

Доступ

Доступ к приложению предоставляется только по логину и паролю администратора. Пользователи без учетной записи не могут просматривать данные.

Хранение данных

Данные хранятся на сервере медицинской системы. Приложение Android является защищенным окном доступа к web-системе и не продает данные третьим лицам.

Удаление и изменение данных

Удаление или изменение данных выполняется администратором системы в соответствии с внутренними правилами организации.

Контакты

По вопросам обработки данных обратитесь к администратору медицинской организации, которая использует эту систему.
