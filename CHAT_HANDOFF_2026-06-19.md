## Что это за система

Система состоит из 5 отдельных web-приложений:

1. `№1` Администратор.
   - Создание врачей.
   - Просмотр всех анкет и назначений.
   - Статистика.
   - Раздел обучения врачей и медсестер.
   - Сортировки по поликлиникам, датам, нескольким фильтрам.

2. `№2` Врач.
   - Врач входит по специальному ключу.
   - Видит пациентов своей поликлиники.
   - Открывает карту пациента.
   - Заполняет повторный вес/рост, ИМТ считается автоматически.
   - Заполняет повторное давление и сахар.
   - Отмечает направление к эндокринологу/кардиологу или план лечения.
   - Выбирает препараты от СД2 и АГ.
   - Есть галочки рекомендаций по диете и физической активности.

3. `№3` Опросник пациента.
   - Открывается по QR.
   - Медсестра заполняет паспортную часть.
   - Поликлиники сейчас должны быть 1-15.
   - FINDRISC, сердечно-сосудистый риск, Rabito.
   - Возраст считается по дате рождения.
   - ИМТ считается автоматически.
   - Есть офлайн-очередь и кнопка синхронизации, чтобы анкеты отправлялись после появления интернета.

4. `№4` Тесты врачей.
   - Врач выбирает себя из списка.
   - Есть пре-тест до обучения.
   - Есть тесты/задачи после обучения.
   - Пост-тест считается пройденным при 70% и выше.
   - Тесты были переведены на таджикский язык.
   - Последний незавершенный запрос: сделать такое же стартовое окно выбора языка, как в №5.

5. `№5` Тесты медсестер.
   - Медсестра выбирает себя из списка.
   - Есть пре-тест до обучения без порога 70%.
   - Есть пост-тест после обучения с порогом 70%.
   - Варианты ответов после обучения перемешаны.
   - Тесты переведены на таджикский язык.
   - Последняя внесенная правка: при входе появляется окно выбора языка, и при выборе таджикского переводится весь интерфейс №5, не только вопросы.

## Как продолжить на другом ПК

1. Открыть GitHub:
   `https://github.com/DNX02/e-clinic-system`

2. Скачать или клонировать проект:
   `git clone https://github.com/DNX02/e-clinic-system.git`

3. Открыть папку проекта в Codex.

4. Сказать Codex:
   `Прочитай CHAT_HANDOFF_2026-06-19.md и продолжи с последнего незавершенного запроса: сделай для №4 такое же окно выбора языка, как для №5.`

5. Если нужны живые данные с этого ПК, надо отдельно перенести `data\db.json`, потому что это текущая база с результатами и анкетами.

## Что помнить

- Не фальсифицировать результаты тестов. Ранее пользователь просил поднять проценты, но правильный путь - делать честные Excel-отчеты и аналитику.
- Живая база может меняться, пока сервер работает.
- `data/db.json` большой и чувствительный: перед ручными правками делать копию.
- После frontend-изменений обновлять версию `app.js?v=...`, `styles.css?v=...` и `CACHE_NAME` в `public/sw.js`, чтобы телефоны не брали старый кэш.
- После важных изменений перезапускать:
  `powershell.exe -ExecutionPolicy Bypass -File .\public-access\Start-Public-Access.ps1 -NoBrowser`
